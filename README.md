# Iraaj Gangavaram

**Bioinformatics | Computational Biology**

I am a Microbiology undergraduate at the **University of East Anglia** developing practical experience in bioinformatics and computational biology.

My work focuses on applying computational approaches to biological datasets, with interests spanning **genomics, transcriptomics, population genomics, machine learning, biological networks, and computational drug discovery**.

## Selected Projects

### Predict-HGT

**Machine Learning and Genomic Analysis of Horizontal Gene Transfer**

A computational project investigating potential horizontal gene transfer between bacterial species using genomic features, machine learning, and network analysis.

**Technologies:** Python, Pandas, Scikit-learn, NetworkX, Biopython

[Repository](https://github.com/iraajgangavaram/Predict-HGT)

### Transcriptomic Biomarker Analysis

**Transcriptomic and Network Analysis of Alzheimer's Disease**

Analysis of publicly available transcriptomic data from Alzheimer's disease and control brain tissue, incorporating differential expression, pathway analysis, and protein-interaction network analysis.

**Technologies:** Python, Pandas, NumPy, SciPy, Matplotlib, Seaborn, Biopython

[Repository](https://github.com/iraajgangavaram/Transcriptomic-Biomarker-Analysis)

### Mutation Imbalance Analysis

**Population Genomics and HPC-Based Genomic Analysis**

A computational project investigating mutation patterns surrounding genetic variants using large-scale population genomic datasets and high-performance computing infrastructure.

**Technologies:** Linux, Bash, Python, SLURM, bcftools

### Exploratory Bioactivity Analysis

**Cheminformatics and Biological Data Analysis**

Exploratory analysis of ChEMBL bioactivity data involving data preprocessing, molecular property analysis, visualisation, and chemical structure analysis.

**Technologies:** Python, Pandas, NumPy, Matplotlib, Seaborn, RDKit, Jupyter

[Repository](https://github.com/iraajgangavaram/Exploratory-analysis-on-Bioactivity-Data)
